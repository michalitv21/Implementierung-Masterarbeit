# Masterarbeit

Dieses Repository enthält den Quellcode zum Tool für meine Masterarbeit: 
Courcelles Theorem in der Praxis: Entscheidung von MSOL-Grapheigenschaften durch übersetzung in Automaten

## Nutzung
Unter /dist findet sich eine ausführbare Datei "courcelleGUI.exe" für Windows.

Alternativ kann man das Tool starten, indem die Datei courcelleGUI.py mit Python ausgeführt wird.
Es sollte die Python Version 3.14 verwendet werden.

## Benötigte Pakete
Für die GUI werden die Python module:

tkinter Version 8.6
customtkinter Version 6.0.0 

benötigt.
